# مدیریت فردی – نسخه اندروید

این مخزن برای ساخت APK اندروید با GitHub Actions آماده شده است.

## ساخت APK در GitHub

1. یک مخزن جدید در GitHub بسازید.
2. تمام محتویات این پوشه را مستقیماً در ریشه مخزن قرار دهید؛ پوشه `.github` باید در ریشه باشد، نه داخل یک پوشه اضافی.
3. تغییرات را در شاخه `main` ثبت کنید.
4. در GitHub وارد زبانه **Actions** شوید و گردش‌کار **Build Android APK** را انتخاب کنید.
5. روی **Run workflow** بزنید و اجرای ساخت را آغاز کنید. با هر push به شاخه `main` یا `master` نیز ساخت خودکار اجرا می‌شود.
6. پس از موفقیت، وارد همان اجرای workflow شوید و از قسمت **Artifacts** فایل `personal-manager-apk` را دانلود کنید.
7. فایل ZIP دانلودشده از Artifacts را باز کنید؛ فایل `app-debug.apk` داخل آن است.

## نکات مهم

- خروجی فعلی، APK آزمایشی/Debug است و برای نصب مستقیم روی گوشی مناسب است؛ برای انتشار رسمی در Google Play باید نسخه Release و امضای اختصاصی ساخته شود.
- برای نصب نسخه جدید روی نسخه قبلی، برنامه را حذف نکنید؛ فایل‌های Debug این پروژه با کلید ثابت موجود در مخزن امضا می‌شوند تا به‌روزرسانی حفظ شود.
- ویجت دستور کار پس از نصب برنامه از بخش Widgets صفحه اصلی اندروید قابل افزودن است.
- داده‌های برنامه به‌صورت محلی روی گوشی نگهداری می‌شوند؛ قبل از حذف برنامه از اطلاعات پشتیبان بگیرید.
